# Doom в CI/CD пайплайне

Помните старую шутку: «На нём можно запустить Doom»? Есть простой и рабочий пример, где классический Doom запускается прямо внутри Buildkite пайплайна. Каждый твой ход становится новым шагом в билде. Это использует динамические пайплайны Buildkite.

**Репозиторий:** https://github.com/buildkite/doom-example
Там же можно посмотреть публичный пайплайн и примеры запусков.

## Как это работает

Пайплайн стартует Doom на агенте. Изображение игры выводится как анимация PNG прямо в дашборде Buildkite.
После каждого действия (хода) пайплайн сам добавляет следующий шаг.

Есть три режима:
- Manual — ты выбираешь действия сам в интерфейсе
- Random — ходы выбираются случайно
- AI —  вместо тебя мучается Claude (нужен ключ от Anthropic)

Когда надоест — просто отменяешь билд, игра заканчивается.

## Что понадобится

- Аккаунт Buildkite (бесплатный триал подойдёт)
- Docker на твоём компьютере
- Опционально: API-ключ Anthropic (для режима с ИИ)

## Пошагово как запустить

1. Форкни репозиторий себе на GitHub.

2. В Buildkite создай новый пайплайн и укажи свой форк.
   Выбери self-hosted агент (облачный не подойдёт).

3. Перейди в Agents → твой кластер → Agent Tokens.
   Создай новый токен и скопируй его.

4. Запусти агент локально (два процесса):

```bash
export BUILDKITE_AGENT_TOKEN="твой_токен_сюда"
export ANTHROPIC_API_KEY="sk-ant-..."   # только если хочешь ИИ-режим

docker run -it --rm \
  -e BUILDKITE_AGENT_TOKEN \
  -e ANTHROPIC_API_KEY \
  buildkite/agent:3-ubuntu start --spawn 2
```
5. В Buildkite нажми New Build на этом пайплайне.

6. Выбери режим игры и играй.
Всё обновляется автоматически в логе билда.
