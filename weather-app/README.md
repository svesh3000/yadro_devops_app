Я выбрал: **Helm + Argo CD** для доставки, **Sealed Secrets** для безопасного хранения секретов в git (в чатике подсмотрел идею) и добавил **Argo CD Image Updater** для автоматического обновления образов (выбрал автоматическое, а не по кнопке, или ручное, или ещё какое-то, чисто потому что автоматическое мне показалось поприкольнее заданием)

## Выбор: Helm + Argo CD

Я не выбрал `kubectl apply` или `kubectl set image` или чисто `Helm`, потому что не хотел трогать пайплайн никак. Мне нравится, когда разные инструменты разделяют между собой ответственность и логику + решил что попробовать GitOps надо.

## Проблемы

### 1. `ImagePullBackOff` у redis в Argo CD

Redis не мог скачать образ из-за таймаутов.

Решение: заменил образ на `redis:7.4-alpine` из Docker Hub, добавил секрет для авторизации в Docker Hub.

### 2. Argo CD не подключался к Git-репозиторию по SSH

В итоге подключился через HTTPS с персональным токеном доступа GitLab.

### 3. `path does not exist` при синхронизации Application

Helm-чарт лежал локально, но не был загружен в Git. Argo CD смотрит в удалённый репозиторий, поэтому я закоммитил папку `weather-app` в GitLab и запушил. В итоге получилось 2 мёрдж реквеста на работу, что, ну, некрасиво.

### 4. Проблема с ResourceQuota и nodeSelector в values.yaml

Helm не мог распарсить вложенные значения. Перестраивал структуру с плоской, на вложенную несколько раз, пока не заработало
